# Linux UART Python 使用说明

## 总线与设备

`JydBus` 管理串口和接收线程。每种传感器由对应类封装，避免调用者反复传递
类型值或把不同传感器的读写操作混用。

```python
from devices import BMP390Sensor
from jydbus_bus import JydBus

with JydBus("/dev/ttyS2", 115200) as bus:
    sensor = BMP390Sensor(bus, sensor_number=1)
    current = sensor.measure_temperature_pressure()
    cached = sensor.read_cached_value()
```

通用方法：

| 方法 | 作用 |
|---|---|
| `request_update()` | 发送查询，不等待响应 |
| `request_data()` | 查询并等待新的原始响应对象 |
| `request_value()` | 查询并返回解码字典 |
| `read_cached_data()` | 读取最新缓存对象，不发送查询 |
| `read_cached_value()` | 读取最新缓存中的解码字典 |
| `write_value(value)` | 写入 32 位配置值 |
| `enable_auto_upload(interval_ms=None)` | 开启自动上传 |
| `disable_auto_upload()` | 关闭自动上传 |

## 类型与专用方法

| 类型 | 类 | 推荐主动读取或控制方法 |
|---:|---|---|
| `0x02` | `AHT10Sensor` | `measure_temperature_humidity()` |
| `0x03` | `BMP390Sensor` | `measure_temperature_pressure()` |
| `0x04` | `MAX30102Sensor` | `measure_heart_rate_oxygen()` |
| `0x05` | `VL53L0XSensor` | `measure_distance()` |
| `0x06` | `MFRC522Reader` | `read_card()` |
| `0x07` | `WS2812BPanel` | `set_pixel_color()`, `display_frame()` |
| `0x08` | `ZW101FingerprintSensor` | `enroll_fingerprint()`, `match_fingerprint()` |
| `0x09` | `ButtonPB1Sensor` | `read_button()` |
| `0x0A` | `JoystickSensor` | `read_position()` |
| `0x0F` | `PhotoresistorSensor` | `measure_light_level()` |
| `0x11` | `WaterLevelSensor` | `measure_water_level()` |
| `0x12` | `SoilMoistureSensor` | `measure_soil_moisture()` |
| `0x13` | `ZSPD4003Sensor` | `measure_heart_rate_oxygen()` |
| `0x14` | `KnobSwitchSensor` | `read_position()` |
| `0x15` | `PAJ7620U2GestureSensor` | `read_gesture()` |
| `0x17` | `FanActuator` | `set_speed()`, `turn_on()`, `turn_off()`, `read_state()` |

也可按运行时类型创建：

```python
device = bus.create_device(sensor_type=0x03, sensor_number=1)
```

PA8 风扇（25 kHz PWM）控制示例：

```python
from devices import FanActuator
from jydbus_bus import JydBus

with JydBus("/dev/ttyS2") as bus:
    fan = FanActuator(bus, 1)
    fan.set_speed(35)
    print(fan.read_state())  # duty_percent 为 35
    fan.turn_off()
```

## 自动上传与缓存

```python
from devices import PAJ7620U2GestureSensor
from jydbus_bus import JydBus

with JydBus("/dev/ttyS2") as bus:
    gestures = PAJ7620U2GestureSensor(bus, 1)
    gestures.enable_auto_upload()
    try:
        print(gestures.read_cached_value())
    finally:
        gestures.disable_auto_upload()
```

缓存尚无数据时会抛出 `OSError`，其 `errno` 为 `ENODATA`。

## ZW101

```python
from devices import ZW101FingerprintSensor
from jydbus_bus import JydBus

with JydBus("/dev/ttyS2") as bus:
    fingerprint = ZW101FingerprintSensor(bus, 1)
    fingerprint.set_operation_timeout(35000)
    fingerprint.enroll_fingerprint(2)
    result = fingerprint.match_fingerprint()
    print(result.fingerprint_id, result.score)
```

还支持 `delete_fingerprint(id)` 和 `clear_fingerprints()`。

## OTA

```python
from sensor_ota import SensorOta

with SensorOta("/dev/ttyS2", 115200) as updater:
    status = updater.get_status(sensor_type=0x15, sensor_number=1)
    updater.upgrade_ab(0x15, 1, "Project_OTA_Slot_A.bin",
                       "Project_OTA_Slot_B.bin", version=2)
```

OTA 还支持 `upgrade_file()` 和 `recovery_upgrade_file()`。恢复模式只能直连
Bootloader，例如 `recovery_upgrade_file(0, "Slot_A.bin", version=2)`。
Slot A/B 镜像必须使用各自正确的链接地址。版本号范围为 `1..0xFFFFFFFF`；
允许同版本重刷，低于设备已确认版本的固件会被拒绝。

## 扫描帧

扫描命令常量为 `JYDBUS_UART_COMMAND_SCAN`。请求 payload 为 ASCII `<<<<`，
响应 payload 为 ASCII `KKKK`。所有帧均校验 CRC16-Modbus；计算范围从长度字段到
payload 末尾，不包含帧头、CRC 和帧尾。
