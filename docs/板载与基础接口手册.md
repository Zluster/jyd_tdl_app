# 板载与基础接口手册

本文面向 CV184X 主板上的 Python 应用开发。示例使用已部署的 `dara`
包（Python 3.10）。接口中的 I2C 编号均为 Linux 总线号：`2` 对应
`/dev/i2c-2`，`4` 对应 `/dev/i2c-4`。

> 除特别说明外，设备对象创建后即可直接调用。

## 一、系统控制

### 1.1 关机

#### 函数

- `os.system(command)`：在 shell 中执行字符串 `command`，返回进程退出码。
- `os.system("poweroff")`：请求 Linux 同步文件系统并关机。通常需要 root
  权限；返回 `0` 仅表示命令已被接受，设备会随即停止运行。
- `AXP2101(2).poweroff()`：通过板载 AXP2101 PMU 请求软件关机；内部已先
  执行文件系统同步。适用于确认板载 PMU 可用的主板。

#### 示例代码

```python
import os

os.system("poweroff")
```

```python
from dara.device.axp2101 import AXP2101

pmu = AXP2101(2)
pmu.poweroff()
```

#### 积木封装

- 样式：`关机`
- 说明：调用系统关机；积木执行后程序不会继续运行，建议在保存数据后使用。

### 1.2 重启

#### 函数

- `os.system("reboot")`：请求 Linux 重启，通常需要 root 权限。
- `AXP2101.reboot()` 当前会抛出 `NotImplementedError`；不要把 PMU 的
  `poweroff()` 当作重启接口。

#### 示例代码

```python
import os

os.system("reboot")
```

#### 积木封装

- 样式：`重启`
- 说明：请求系统重启；执行后当前程序立即结束。

## 二、文件类

### 2.1 文件刷新

Python 写文件先进入用户态缓冲；`flush()` 将缓冲交给内核，`os.fsync()`
进一步要求内核将文件数据写入存储设备。保存关键配置、学习库或日志时应使用两者。

#### 函数

- `file.flush()`：刷新 Python 文件对象缓冲。
- `os.fsync(file.fileno())`：同步文件描述符对应的数据和元数据到存储设备。

#### 示例代码

```python
import os

file = open("/root/jyd_app/data/settings.txt", "w", encoding="utf-8")
file.write("volume=16\n")
file.flush()
os.fsync(file.fileno())
file.close()
```

#### 积木封装

- 样式：`刷新文件 [文件对象]`
- 说明：将此前写入文件对象的数据尽量立即落盘；应在“写入文件”之后调用。

### 2.2 文件保存

#### 函数

- `open(path, "w", encoding="utf-8")`：以覆盖方式创建或写入文本文件。
- `open(path, "wb")`：以覆盖方式写入二进制文件。
- `os.replace(temp_path, path)`：用临时文件原子替换目标文件，避免掉电时留下半个配置文件。

#### 示例代码

```python
import json
import os

path = "/root/jyd_app/data/settings.json"
temp_path = path + ".tmp"
os.makedirs(os.path.dirname(path), exist_ok=True)
file = open(temp_path, "w", encoding="utf-8")
json.dump({"volume": 16}, file, ensure_ascii=False)
file.flush()
os.fsync(file.fileno())
file.close()
os.replace(temp_path, path)
```

#### 积木封装

- 样式：`保存文本 [内容] 到 [路径]`
- 说明：将文本覆盖写入指定路径；需要保留旧文件时，积木层应先另存备份。

## 三、板载外设

### 3.1 屏幕

#### 3.1.1 屏幕亮度控制

当前 `dara` 没有独立的“屏幕背光亮度”公开接口。`lv` 用于 UI/图像显示，
但 LVGL 控件的颜色或透明度不等于物理背光亮度；若要开放此能力，应先确认背光
PWM/PMU 通道后再在板级配置中新增封装。

#### 图像显示示例

```python
from dara import camera, lv

while True:
    # read_image() 返回前摄 grp0/ch0 的 BGR 图像；show() 显示最新图像。
    lv.show(camera.read_image())
```

### 3.2 扬声器

#### 3.2.1 扬声器音量控制

使用 `dara.audio.Audio`。输出音量由 `output_volume` 指定，当前板端范围由
底层音频驱动限制（通常为 `0` 到 `32`，`0` 为静音）；推荐以 `16` 作为初值。

#### 函数

| 函数 | 参数与作用 |
|---|---|
| `Audio.set_output_volume(volume)` | 设置扬声器/耳机输出音量，成功返回 `True`。 |
| `Audio.output_volume()` | 返回当前输出音量。 |
| `Audio.play_wav(path, output_volume=16, timeout_ms=1000)` | 播放 PCM WAV 文件；`path` 是文件路径。 |

#### 示例代码

```python
from dara.audio import Audio

audio = Audio()
audio.set_output_volume(16)
audio.play_wav("/root/jyd_app/share/hello.wav", output_volume=16)
```

#### 积木封装

- 样式：`设置扬声器音量为 [16]`、`播放音频文件 [路径]`
- 说明：音量建议限制在板端实际支持范围内；播放失败时读取 `last_error` 排查。

### 3.3 RGB 灯

RGB 灯由小核服务驱动，不应直接通过 GPIO 操作。先调用 `tdl_py.init()`，
再创建 `tdl_py.RgbLed`；`set_all()` 与 `set_pixel()` 只改缓存，必须调用
`show()` 才会一次性输出，避免跑马灯逐颗闪烁。

#### 函数

| 函数 | 参数与作用 |
|---|---|
| `tdl_py.RgbLed(pixel_count=14)` | 创建 LED 控制器；`pixel_count` 范围为 1 到 14。 |
| `set_all(r, g, b)` | 设置全部灯的 RGB 缓存，三个分量均为 0 到 255。 |
| `set_pixel(index, r, g, b)` | 设置指定灯；`index` 从 0 开始。 |
| `brightness(value)` | 设置全局亮度（0 到 255），之后调用 `show()` 生效。 |
| `show()` | 将当前缓存提交到小核。 |
| `clear()` | 熄灭所有灯。 |

#### 示例代码

```python
import time
import tdl_py

tdl_py.init()
led = tdl_py.RgbLed(pixel_count=14)
led.set_all(0, 80, 0)
led.show()
time.sleep(1)
led.clear()
```

#### 积木封装

- 样式：`所有 RGB 灯显示颜色 [红]`、`第 [0] 颗 RGB 灯显示 (R,G,B)`、`熄灭 RGB 灯`
- 说明：颜色积木内部应在设置后自动调用 `show()`；应用结束时自动调用 `clear()`。

### 3.4 麦克风（响度）

当前 `dara.audio.Audio` 已提供录音、原始 PCM 获取和回放，但**没有**公开的
“实时响度/dB”计算接口。可通过 `capture_pcm()` 获取 16-bit PCM 后由上层计算 RMS。

#### 函数

| 函数 | 参数与作用 |
|---|---|
| `Audio.capture_pcm(seconds=3.0, sample_rate=16000, channels=1, input_volume=40, points_per_frame=320, timeout_ms=1000)` | 录制并返回 16-bit PCM `bytes`；出错返回 `None`。 |
| `Audio.set_input_volume(volume)` | 设置麦克风输入音量，成功返回 `True`。 |
| `Audio.record_wav(path, ...)` | 将录音直接保存为标准 WAV 文件。 |

#### 示例代码

```python
import array
import math
from dara.audio import Audio

audio = Audio()
pcm = audio.capture_pcm(seconds=0.2)
samples = array.array("h")
samples.frombytes(pcm)
rms = math.sqrt(sum(sample * sample for sample in samples) / len(samples))
print("RMS:", round(rms, 1))
```

#### 积木封装

- 样式：`获取声音响度`
- 说明：积木应取一个较短采样窗口并返回 RMS 数值；它反映相对响度，不是经标定的 dB SPL。

### 3.5 摄像头

#### 3.5.1 摄像头选择

`dara.camera` 按小核固定 VPSS 路由提供工厂函数。前摄与后摄都可取 RGB、AI、预览
或 320×240 传统视觉通道；后摄要求小核已经启动对应的 `grp3` 采集。

| 函数 | VPSS 路径 | 用途 |
|---|---|---|
| `camera.rgb()` / `camera.rear_rgb()` | grp0/ch0 / grp3/ch0 | 720×480 BGR 图像处理。 |
| `camera.ai()` / `camera.rear_ai()` | grp0/ch1 / grp3/ch1 | 640×640 RGB planar NPU 输入。 |
| `camera.live()` / `camera.rear_live()` | grp0/ch2 / grp3/ch2 | 720×480 NV12 预览。 |
| `camera.sub_rgb()` / `camera.rear_sub_rgb()` | grp0/ch3 / grp3/ch3 | 320×240 BGR 传统视觉。 |
| `camera.screen()` | grp1/ch0 | 720×480 最终合成显示通道。 |

#### 示例代码

```python
from dara import camera

# 前摄 RGB 图像。图像到下一次同通道读取前有效。
image = camera.rgb().read_image()
image.save("/tmp/front.jpg")

# 后摄 RGB 图像。
rear_image = camera.rear_rgb().read_image()
rear_image.save("/tmp/rear.jpg")

# 控制屏幕预览来源："front"、"rear" 或 "off"。
camera.preview("front")
```

#### 积木封装

- 样式：`选择摄像头 [前摄/后摄]`、`拍照保存到 [路径]`、`显示摄像头预览`
- 说明：AI 推理积木使用 AI 通道；传统颜色/二维码算法优先使用 RGB 或 sub-RGB 通道。

### 3.6 光线传感器

板载 LTR390 使用 I2C2、默认地址 `0x53`。环境光模式返回 lux；紫外模式返回
UV Index。构造后默认已打开。

#### 函数

| 函数 | 参数与作用 |
|---|---|
| `LTR390(2, mode=LTR390Mode.AMBIENT_LIGHT)` | 创建环境光传感器。 |
| `read_brightness()` | 环境光模式返回 lux；紫外模式返回 UV Index。 |
| `read_raw()` | 返回传感器原始计数。 |
| `read_all()` | 返回对象，其 `.brightness` 为上述结果。 |
| `reset(mode, gain, resolution, threshold)` | 修改采样模式、增益、分辨率和可选阈值。 |

#### 示例代码

```python
from dara.device.ltr390 import LTR390, LTR390Mode

light = LTR390(2, mode=LTR390Mode.AMBIENT_LIGHT)
print("brightness: %.2f lux" % light.read_brightness())
```

#### 积木封装

- 样式：`获取环境光照度`
- 说明：返回 lux 浮点数；切到紫外模式后同一积木返回 UV Index，应在积木名称中明确模式。

### 3.7 陀螺仪

板载 QMI8658 使用 I2C2、默认地址 `0x6B`。`read_all()` 一次获取三轴加速度、
三轴角速度与芯片温度。

#### 函数调用

```python
from dara.device.qmi8658 import QMI8658

# 参数 2 是 Linux I2C 总线号，对应 /dev/i2c-2。
imu = QMI8658(2)
sample = imu.read_all()
acc_x, acc_y, acc_z = sample.acc       # 单位 g
gyro_x, gyro_y, gyro_z = sample.gyro   # 默认单位 deg/s
print("acc:", sample.acc, "gyro:", sample.gyro)
```

#### 初始校准

- `imu.calib_gyro(time_ms, interval_ms=-1, save_id="default")`：板子保持静止，
  采样指定毫秒数计算陀螺仪零偏；默认保存到
  `/data/etc/dara/imu_calibration.json`。
- `imu.load_calib_gyro(save_id="default")`：加载已保存的陀螺仪零偏。
- `imu.calibrate_all(sample_count=100, interval_ms=10, acc_target=None)`：执行
  COD、陀螺仪零偏和加速度计零偏校准。校准期间必须保持静止，并让某一个传感器轴
  大致垂直；返回字典，以 `result["success"]` 判断是否成功。

```python
from dara.device.qmi8658 import QMI8658

imu = QMI8658(2)
# 设备静止后执行；约需数秒。
result = imu.calibrate_all(sample_count=100, interval_ms=10)
print("是否成功:", result["success"])
print("陀螺仪偏移:", result["gyro_offset_dps"])
```

#### 俯仰、横滚与相对航向

`QMI8658` 已提供内置姿态解算接口，无需应用手动创建滤波器对象：

```python
attitude = imu.read_attitude()
print("roll=%.1f pitch=%.1f yaw=%.1f" % (
    attitude.roll, attitude.pitch, attitude.yaw))
```

- `read_attitude(dt=None)`：读取一帧并用内部互补滤波器更新姿态。`dt` 单位为秒；实时读取时可省略。
- `reset_attitude(roll=0, pitch=0, yaw=0)`：重置姿态与时间基准。
- `configure_attitude(correction=0.02, reference_hz=100)`：调整内部滤波器参数。默认 correction=0.02，即约 98% 陀螺仪与 2% 重力校正。
- `.roll`、`.pitch`、`.yaw` 单位均为度；六轴 IMU 没有绝对北向参考，`yaw` 是相对角且会漂移。

#### 积木封装

- 样式：`初始化陀螺仪`、`校准陀螺仪`、`获取 [X/Y/Z] 轴加速度`、`获取 [X/Y/Z] 轴角速度`、`获取 [横滚/俯仰/相对航向]`
- 说明：加速度单位为 g，角速度默认单位为 deg/s；姿态积木调用 `read_attitude()`，并标注 yaw 为相对角、会漂移。

### 3.8 温湿度传感器

板载 AHT20 使用 I2C2、默认地址 `0x38`。

#### 函数

| 函数 | 参数与作用 |
|---|---|
| `AHT20(2, temperature_offset=0.0, humidity_offset=0.0)` | 创建传感器；两个 offset 用于补偿，单位分别为 °C 和 %RH。 |
| `read_temperature()` | 返回温度，单位 °C。 |
| `read_humidity()` | 返回相对湿度，单位 %RH。 |
| `read_all()` | 返回对象，含 `.temperature` 与 `.humidity`。 |

#### 示例代码

```python
from dara.device.aht20 import AHT20

sensor = AHT20(2)
data = sensor.read_all()
print("temperature=%.1f C humidity=%.1f %%RH" %
      (data.temperature, data.humidity))
```

#### 积木封装

- 样式：`获取温度`、`获取湿度`
- 说明：温度单位 °C，湿度单位 %RH；一次需要两个数值时应使用同一次 `read_all()`。

### 3.9 触摸

触摸事件通过 `dara.lv` 从 LVGL 对象收集，而不是直接读取 `/dev/input/event*`。
先对要接收事件的对象调用 `lv.bind_touch(obj)`，再循环调用 `lv.read_touch()`。

#### 函数

| 函数 | 参数与作用 |
|---|---|
| `lv.bind_touch(obj)` | 为一个 LVGL 对象绑定按下、移动、释放事件队列。 |
| `lv.read_touch()` | 返回下一条 `(phase, x, y)`，没有事件时返回 `None`；`phase` 为 `pressed`、`moving` 或 `released`。 |

#### 示例代码

```python
from dara import lv

screen = lv.screen_active()
lv.bind_touch(screen)

while True:
    event = lv.read_touch()
    if event is not None:
        phase, x, y = event
        print(phase, x, y)
    lv.show(30)
```

#### 积木封装

- 样式：`当屏幕被 [按下/移动/松开] 时`，`触摸 X`，`触摸 Y`
- 说明：积木运行时持续读取队列；移动事件可能很多，应避免每次移动执行耗时操作。

### 3.10 按键

`SoftKey` 会在后台线程中维护按键状态。当前板级配置包含 `"A"` 与 `"B"`
两个 ADC 按键；普通短按与长按在**松开**时确认。

#### 函数

| 函数 | 参数与作用 |
|---|---|
| `SoftKey(id, long_press_ms=2000)` | 创建按键；长按阈值为毫秒，设为 `None` 可关闭长按识别。 |
| `is_down()` / `is_long_down()` | 当前是否按下 / 当前按下是否已达到长按时间。 |
| `is_pressed()` / `is_long_pressed()` | 消费一次短按 / 长按事件；读取后该事件被清除。 |
| `set_callback(callback)` | 设置回调；回调参数为 `SoftKeyEvent`。 |

#### 示例代码

```python
import time
from dara.peripheral.softkey import SoftKey

key = SoftKey("A", long_press_ms=1500)
while True:
    if key.is_pressed():
        print("short press")
    if key.is_long_pressed():
        print("long press")
    time.sleep(0.02)
```

#### 积木封装

- 样式：`当按键 [A/B] 被短按`、`当按键 [A/B] 被长按`
- 说明：一次按键事件只触发一次；短按与长按均在松开按键后生效。

### 3.11 RTC 时间

当前 `dara` 尚没有 RTC 读取、写入或后备电源管理的公开 Python 类。RTC 驱动、
`/dev/rtc0` 与 `hwclock` 可用性属于内核/根文件系统配置；在 Dara 增加明确封装前，
不应在积木中宣称 RTC 时间可用。

系统时间可临时使用标准库读取：

```python
from datetime import datetime
print(datetime.now().isoformat(sep=" ", timespec="seconds"))
```

## 四、图像显示与处理相关

### 4.1 image 模块相关

`dara.image` 转发板端 `_maix_image` 图像对象。常用路径是：摄像头取得
`Image`，调用图像算法或 `save()`，再用 `lv.show(image)` 显示。

```python
from dara import camera, lv

image = camera.sub_rgb().read_image()
codes = image.find_qrcodes()
for code in codes:
    print(code["payload"])
image.save("/tmp/qrcode-frame.jpg")
lv.show(image)
```

注意：`camera.read_image()` 返回的图像缓冲会在下一次同通道读取时失效。需要长期
保存图像时应立即调用 `image.save(path)` 或执行明确的图像复制。

### 4.2 lv 模块相关

`dara.lv` 是嵌入式 LVGL 代理。UI 线程会自动刷新；`lv.show(fps)` 只用于
控制应用循环节奏，`lv.show(image)` 用于显示最新图像。

```python
from dara import lv

screen = lv.screen_active()
label = lv.label(screen)
label.set_text("Hello CV184X")
label.center()

while True:
    lv.show(30)
```

## 五、音频分析与处理相关

### 5.1 声音频谱分析

当前 `dara.audio` 没有公开的 FFT/频谱分析接口。可先用 `Audio.capture_pcm()`
取 PCM，再由上层 NumPy 或自实现 FFT 分析；若镜像未带 NumPy，不应在应用中假设其存在。

### 5.2 声源定位

当前板级 `dara` 没有声源定位（DOA）公开接口。单麦克风录音不能确定二维方向；
需要多麦阵列、同步采样与定位算法后才能提供该积木。

### 5.3 音频加载与播放

#### 函数

- `Audio.play_wav(path, output_volume=16, timeout_ms=1000)`：播放 PCM WAV。
- `Audio.loopback(seconds=3.0, sample_rate=16000, channels=1, input_volume=40,
  output_volume=16, points_per_frame=320, timeout_ms=1000)`：将麦克风直接送到输出，
  用于录放链路验证。

```python
from dara.audio import Audio

audio = Audio()
audio.play_wav("/root/jyd_app/share/tone.wav")
```

### 5.4 音频录制与保存

#### 函数

- `Audio.record_wav(path, seconds=3.0, sample_rate=16000, channels=1,
  input_volume=40, points_per_frame=320, timeout_ms=1000)`：录音并写入 WAV。
- `Audio.capture_pcm(...)`：录音并返回裸 PCM 字节；需要由调用方决定保存格式。

```python
from dara.audio import Audio

audio = Audio()
audio.record_wav("/tmp/record.wav", seconds=3.0,
                 sample_rate=16000, input_volume=40)
```

## 六、板载有线通信

### 6.1 GPIO

GPIO 通过板级 pin map 选择，当前明确配置了 `"LED"`。`GPIO` 的 `id` 是板级
标识符，而不是随意填写 Linux 行号。

```python
import time
from dara.peripheral.gpio import GPIO, GPIODirection

led = GPIO("LED", GPIODirection.OUT)
```

输入边沿示例：

```python
from dara.peripheral.gpio import GPIO, GPIODirection, GPIOEdge

pin = GPIO("MY_INPUT", GPIODirection.IN, edge=GPIOEdge.BOTH)
if pin.poll(1.0):                 # 最多等待 1 秒
    event = pin.read_event()
    print(event.edge, event.timestamp)
```

`MY_INPUT` 必须先在板级 `PinMap` 中配置，否则构造会失败。

### 6.2 ADC

当前映射的 ADC 为 `"ADCBTN"`，主要供板载按键使用。`read_raw()` 返回原始
12-bit 计数，`read_vol()` 根据配置的 1.5V 参考电压换算为伏特。

```python
from dara.peripheral.adc import ADC

adc = ADC("ADCBTN")
print("raw:", adc.read_raw())
print("voltage: %.3f V" % adc.read_vol())
```

### 6.3 PWM

`PWM(id, freq=None, duty=None, enable=None)` 控制已在板级 pin map 声明的 PWM。
`duty` 是 `0.0` 到 `1.0` 的占空比，`freq` 单位 Hz。当前主板配置尚未公开 PWM
标识符；先完成 pin map 与 DTS 配置，再面向应用使用该类。

```python
from dara.peripheral.pwm import PWM

# "PWM_EXAMPLE" 必须是已配置的板级 PWM 名称。
pwm = PWM("PWM_EXAMPLE", freq=1000, duty=0.5, enable=True)
pwm.set_duty(0.2)
```

### 6.4 UART

当前板级映射：`"UART1"` 为 `/dev/ttyS0`，`"UART2"` 为 `/dev/ttyS2`；后者需
先在 DTS 中启用。`timeout` 单位为秒：`None`/负数无限等待，`0` 不等待。

```python
from dara.peripheral.uart import UART

uart = UART("UART1", baudrate=115200)
uart.write_str("hello\\r\\n")
uart.flush()                      # 刷新输出缓冲
reply = uart.readline_str(timeout=1.0)
print("reply:", reply)
```

### 6.5 IIC（I²C）

`I2C(id)` 接收 Linux 总线号或板级名称。已配置 `I2C2` 与 `I2C4`；推荐驱动类
直接传入 `2` 或 `4`，例如 `QMI8658(2)`。

#### 函数

| 函数 | 参数与作用 |
|---|---|
| `I2C(2)` / `I2C("I2C2")` | 打开 `/dev/i2c-2`。 |
| `scan()` | 返回应答的 7-bit 地址列表。 |
| `read(addr, nbytes)` / `write(addr, data)` | 直接读写设备。 |
| `read_mem(addr, memaddr, nbytes)` | 从 8-bit 寄存器地址读取。 |
| `write_mem(addr, memaddr, data)` | 向 8-bit 寄存器地址写入。 |
| `read_mem_byte(addr, memaddr)` / `write_mem_byte(addr, memaddr, value)` | 单字节寄存器便捷接口。 |

#### 示例代码

```python
from dara.peripheral.i2c import I2C

i2c = I2C(2)
print("devices:", ["0x%02x" % addr for addr in i2c.scan()])
# 示例：读取 AXP2101 的版本寄存器 0x03，设备地址是 0x34。
version = i2c.read_mem_byte(0x34, 0x03)
print("AXP2101 version: 0x%02x" % version)
```

#### 积木封装

- 样式：`I2C [2] 总线扫描`、`I2C [2] 读取设备 [0x34] 寄存器 [0x03]`
- 说明：地址使用 7-bit 地址（例如 AXP2101 是 `0x34`），不要传 Linux 8-bit 读写地址。

## 附录：当前板载默认 I²C 设备

| 设备 | 总线 | 默认地址 | 常用类 |
|---|---:|---:|---|
| AXP2101 PMU | 2 | `0x34` | `dara.device.axp2101.AXP2101` |
| QMI8658 IMU | 2 | `0x6B` | `dara.device.qmi8658.QMI8658` |
| MMC56X3 磁力计 | 2 | `0x30` | `dara.device.mmc56x3.MMC56X3` |
| AHT20 温湿度 | 2 | `0x38` | `dara.device.aht20.AHT20` |
| LTR390 光线/紫外 | 2 | `0x53` | `dara.device.ltr390.LTR390` |

完整设备清单仍应以 `I2C(2).scan()` 和实际硬件装配为准。
