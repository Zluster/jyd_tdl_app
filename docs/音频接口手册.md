# 音频接口手册

`dara.audio` 是 `tdl_py` 音频接口的稳定入口。其算法实现使用 CPU Kaldi
Fbank 与 CV184X BMRT BF16 bmodel，不依赖 Sherpa、ONNX Runtime 或 `.onnx`
模型。

```python
from dara import audio

io = audio.Audio()
pcm = io.capture_pcm(3.0)
```

算法 PCM 参数统一为：16 kHz、单声道、signed 16-bit little-endian `bytes`。

## 基础音频

```python
io.record_wav("/tmp/test.wav", 3.0)
io.play_wav("/tmp/test.wav")
io.loopback(3.0)
```

默认构建仅播放 PCM WAV。`record_wav()`、`play_wav()` 与 `loopback()` 失败时
返回 `False`，`capture_pcm()` 失败时返回 `None`，详情读取 `io.last_error`。

## 声纹识别

```python
speaker = audio.SpeakerRecognizer()
speaker.load("/root/tdl_app_sdk_cv184x/configs/model_specs/speaker_campplus_sv.mud")
speaker.enroll("alice", pcm)
speaker.save_database("/tmp/speakers.db")
print(speaker.recognize(pcm, threshold=0.60))
```

## 流式 ASR

```python
asr = audio.StreamingAsr()
asr.load("/root/tdl_app_sdk_cv184x/configs/model_specs/npu_zipformer_zh_14m_asr.mud")
partial = asr.accept(io.capture_pcm(0.8))
final = asr.finish()
```

## 关键词检测

```python
kws = audio.KeywordSpotter()
kws.load(
    "/root/tdl_app_sdk_cv184x/configs/model_specs/npu_zipformer_zh_kws.mud",
    "/root/tdl_app_sdk_cv184x/configs/kws_keywords.default.txt",
    beam_width=6,
)
hits = kws.accept(io.capture_pcm(0.8))
scores = kws.scores()
```

`accept()` 只返回本次新触发的关键词；`scores()` 返回所有配置关键词的当前
`confidence`、`threshold`、匹配 token 数和触发状态。

## 文字转语音（TTS）

中文文本进、16 kHz 单声道 PCM 出。文本前处理（数字、标点、多音字读音表）
全部在 C++ 侧完成，Python 侧不需要 pypinyin、不需要预先准备音频，也不起
任何子进程；一个 `.mud` 描述文件里同时写明音素前端与解码器两个 bmodel，
调用方只关心文本和 PCM。

```python
tts = audio.TextToSpeech()
tts.load("/root/models/piper_zh_tts.mud")   # 首次合成前加载一次即可

print(audio.TextToSpeech.SAMPLE_RATE)       # 16000

pcm = tts.run("今天天气真不错")               # bytes，失败返回 None
tts.synthesize("你好，我是智能助手。", "/tmp/tts.wav")

io.play_wav("/tmp/tts.wav")                 # 或交给 audio.WavPlayer 播放
tts.reset()                                 # 释放 NPU，退出应用前调用
```

接口一览：

| 接口 | 说明 |
| --- | --- |
| `load(model_spec)` | 载入 `.mud`（含前端与解码器 bmodel）。成功返回 `True` |
| `run(text)` | 合成一段文本，返回 16 kHz 单声道 16-bit LE PCM `bytes`；失败返回 `None` |
| `synthesize(text, wav_path)` | 同上并写入标准 WAV 文件，成功返回 `True` |
| `tokens(text)` | 只做前处理，返回按分句切开的音素 id 列表，用于调试 |
| `reset()` | 归还 NPU 设备内存；之后可再次 `load()` |
| `initialized` | 模型是否已加载 |
| `stats` | 上次合成的 `chunks` / `rendered` / `frames` / `samples` / `duration` |
| `last_error` | 失败原因 |

长文本会按标点自动切分成多段分别推理再拼接，`stats["chunks"]` 就是段数。
模型只在首次合成前加载，`reset()` 之后 NPU 设备内存立即归还——反复进入和
退出应用不会累积占用。

对应的 `.mud` 写法：

```ini
[basic]
type = tts_bundle
model = piper_zh_tts_realdur32_192_bf16.bmodel

[extra]
runtime = bmrt
task = text_to_speech
frontend_model = piper_zh_tts_realdur32_192_bf16.bmodel
decoder_model = piper_zh_decoder_len192_v127_bf16.bmodel
sample_rate = 22050
output_sample_rate = 16000
```
