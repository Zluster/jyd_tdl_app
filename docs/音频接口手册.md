# 音频接口手册

`dara.audio` 是 `tdl_py` 音频接口的稳定入口。其算法实现使用 CPU Kaldi
Fbank 与 CV184X BMRT BF16 bmodel，不依赖 Sherpa、ONNX Runtime 或 `.onnx`
模型。

```python
from dara import audio

io = audio.Audio()
pcm = io.capture_pcm(3.0)
```

算法 PCM 参数统一为：16 kHz、单声道、signed 16-bit little-endian `bytes`。

## 基础音频

```python
io.record_wav("/tmp/test.wav", 3.0)
io.play_wav("/tmp/test.wav")
io.loopback(3.0)
```

默认构建仅播放 PCM WAV。`record_wav()`、`play_wav()` 与 `loopback()` 失败时
返回 `False`，`capture_pcm()` 失败时返回 `None`，详情读取 `io.last_error`。

## 声纹识别

```python
speaker = audio.SpeakerRecognizer()
speaker.load("/root/tdl_app_sdk_cv184x/configs/model_specs/speaker_campplus_sv.mud")
speaker.enroll("alice", pcm)
speaker.save_database("/tmp/speakers.db")
print(speaker.recognize(pcm, threshold=0.60))
```

## 流式 ASR

```python
asr = audio.StreamingAsr()
asr.load("/root/tdl_app_sdk_cv184x/configs/model_specs/npu_zipformer_zh_14m_asr.mud")
partial = asr.accept(io.capture_pcm(0.8))
final = asr.finish()
```

## 关键词检测

```python
kws = audio.KeywordSpotter()
kws.load(
    "/root/tdl_app_sdk_cv184x/configs/model_specs/npu_zipformer_zh_kws.mud",
    "/root/tdl_app_sdk_cv184x/configs/kws_keywords.default.txt",
    beam_width=6,
)
hits = kws.accept(io.capture_pcm(0.8))
scores = kws.scores()
```

`accept()` 只返回本次新触发的关键词；`scores()` 返回所有配置关键词的当前
`confidence`、`threshold`、匹配 token 数和触发状态。
