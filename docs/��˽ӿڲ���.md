# Dara 板端接口测试

本目录是 `dara` Python 包本身。它不包含应用的 `app.yaml`；应用描述文件属于
`jyd_app/apps/`，与 wheel 打包、导入和板级驱动无关。

## 模块边界

| 模块 | 用途 | 是否可直接在板端测试 |
| --- | --- | --- |
| `core` | 注册表、事件基类、日志、异常转换 | 可以，无硬件副作用 |
| `peripheral` | PinMap、GPIO、I2C、SPI、UART、PWM、ADC、软按键、看门狗 | 可以；GPIO/PWM/UART/SPI 写入须由测试者明确接线 |
| `device` | AXP2101、QMI8658、MMC56X3、AHT20、VL53L0X 等具体设备驱动 | 可以；取决于实际挂载的 I2C/GPIO 硬件 |
| `iot` | Wi-Fi 站/AP 管理和 Bluetooth/BlueZ 封装 | 可以；Wi-Fi 状态只读，蓝牙需要 `dbus-fast` 与 `bluetoothd` |

`_periphery/` 是 `peripheral` 的 Linux ioctl/sysfs 后端，不应作为公开 API。
`*.pyi` 是类型提示，运行时 Python 只执行同名 `.py`，但应保留以支持编辑器补全。
`_libs/*.so` 是 CV184x ARM 原生绑定，wheel 运行必需，不能移除。

## YAML 已移除

IMU 陀螺仪校准档案使用标准库 JSON：

```text
/data/etc/dara/imu_calibration.json
```

因此不再需要 `PyYAML` 或 `sensors` optional dependency。旧的
`imu_calibration.yaml` 不会自动读取；如有已有校准值，按相同的字典结构转存到
JSON，或在板端重新执行一次 `imu.calib_gyro(..., save_id="default")`。

## 一键 smoke 测试

安装最新 wheel 后执行：

```sh
python3 /root/jyd_tdl_app/tests/board_api_smoke.py
python3 /root/jyd_tdl_app/tests/board_api_smoke.py --group peripheral --active
python3 /root/jyd_tdl_app/tests/board_api_smoke.py --group device --active
python3 /root/jyd_tdl_app/tests/board_api_smoke.py --group iot
```

不带 `--active` 时仅验证导入、核心逻辑和 PinMap 元数据。`--active` 会设置已配置
I2C 引脚复用、扫描 I2C，并对识别到的 AXP2101/QMI8658/MMC56X3 做一次读取；不会
改 GPIO、PWM、UART、SPI、Wi-Fi 模式、蓝牙状态或看门狗。

设备未接入时显示 `SKIP` 是正常结果；`FAIL` 说明已配置但驱动、设备节点或总线通信
存在问题。

## 逐项接口例子

```python
from dara.core.registry import Registry
from dara.core import log

drivers = Registry("demo")
log.info("Dara core is ready")
```

```python
from dara.peripheral.i2c import I2C

with I2C("I2C0") as bus:
    print(bus.scan())
```

```python
from dara.device.qmi8658 import QMI8658
from dara.peripheral.i2c import I2C

with I2C("I2C0") as bus, QMI8658(bus) as imu:
    print(imu.read_all())
```

```python
from dara.iot.wifi import Wifi

wifi = Wifi()
print(wifi.status())
print(wifi.get_ip())
```

GPIO、PWM、UART、SPI 是外设控制接口，必须根据实际原理图和连接的负载测试。例如
`GPIO("LED", GPIODirection.OUT).write(True)` 会改变 LED 管脚电平，不放入自动化
smoke 测试。
